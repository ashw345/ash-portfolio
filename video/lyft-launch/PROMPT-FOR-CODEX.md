# 任务：重制 Lyft Street View 产品介绍视频

## 背景

`video/lyft-launch/` 下有一支已完成的成片 `lyft-street-view-full.mp4`（104 秒，1920x1080，30fps），
由 `render-full.swift` 渲染。原始设计稿素材在 `LyftPPT/` 文件夹。

这一版的问题已经量化诊断过，需要按下面的要求重做。目标是让成片看起来像苹果的产品发布宣传片：
克制、连贯、有空间纵深，而不是带旁白的 PPT 翻页。

---

## 一、必须修复的核心问题

### 1. 画面有 47% 的时间是完全静止的

实测方法：逐帧计算帧间差（缩放到 160x90 转灰度后取平均），104 秒里有 **49 秒**的帧间差 ≈ 0。
典型模式是：切镜 → 1 秒动效 → 冻结 4 秒等旁白念完。

根因有两个：

- **时间轴被 TTS 音频长度驱动**。`render-full.swift` 按 cue 时长排 timeline，动效跑完画面就死等。
- **场景 6–14 直接用了拍平的整页 PNG**：`6/6.png`、`7/7.png`、`8/8.png`、`9/9.png`、`10.png`、
  `11&12/11.png`、`11&12/12.png`、`13&14/13.png`、`13&14/14.png`。整张图一个图层，物理上无法做动效。

**要求**：

- 场景 6–14 全部拆成独立元素动画（素材已存在，见第三节）。
- 所有镜头加入**永不停止的底层运动**：每秒 0.3–0.8% 的缓慢推进或位移。
  苹果的片子里画面从不完全静止，"呼吸感"就来自这里。
- 验收标准：帧间差 < 0.06 的秒数必须为 **0**。

### 2. 转场是在运动图层上做交叉溶解

第 7.8 秒前后两个还在运动的画面直接叠加，出现明显鬼影脏帧，字幕也叠了两层。

另外 0–8 秒推手机时，**推进过程中手机被画面底部裁掉，但粉色圆还在**，构图直接破了。

**要求**：禁止使用 opacity 交叉溶解。只允许这三类转场：

- **匹配剪辑**：手机屏幕推到满屏后，直接切到下一幕的对应元素（封面 → 方向盘照片这一处最适合）
- **遮罩推出**：用 Lyft 粉的形状做 wipe，形状本身携带信息
- **穿透缩放**：推进到某个元素内部再拉出；两侧画面必须朝**同一方向**运动，读起来才是一个连续的动作

深色场景转到白色场景时，前一个镜头必须淡向**白色**（不是黑色），否则会出现黑→白的跳变。

### 3. 完全没有合成细节

`render-full.swift` 里 grep `blur` / `shadow` / `grain` / `vignette` / `depthOfField`，**一个都没有**。
画面是纯平贴图。

**要求补齐**：

- **运动模糊**：快速位移的车辆、推进的镜头必须带（按速度沿运动矢量采样 5 次）
- **接触阴影**：手机、卡片、头像要有柔和投影（大模糊半径、低透明度，约 0.2–0.3）
- **景深**：元素入场时从失焦到合焦；推进时背景轻微失焦
- **胶片颗粒 + 暗角**：极轻微，颗粒强度约 2/255，暗角约 10%

### 4. 缓动曲线平庸

现在是 35 处 `easeOut` + 13 处 `easeInOut`，是系统标准缓动，"正确但平庸"。

**要求**：改成长尾缓出，`cubic-bezier(0.22, 1, 0.36, 1)` 这类曲线——前 30% 走完 80% 的距离，
后面慢慢沉降。

### 5. 字幕

- 字号约 24px @1080p，**太小**，应为 38–44px
- 字体用了 `HelveticaNeue`，**它没有中文字形**，中文全在走系统回退字体，中英文字重不统一。
  中文改用 `PingFang SC`
- 压在街景/地图上没有底衬，可读性差
- 字幕和旁白**逐字相同**，形成三重重复（画面英文标题 + 旁白中文 + 字幕中文）

**要求**：英文在上（约 31px，浅灰），中文在下（约 38px），底部居中。深色背景加渐变遮罩。
入场用淡入 + 上移 14px，出场只淡出不移动。

**注意**：`11&12` 这两张稿子自带的 "User Experience Journey" 标题位于画面底部
（1080 空间约 y=940–1010），会和字幕撞。这一幕的字幕需要整体上移约 168px。

### 6. 节奏与叙事

- 成片 104 秒，原计划是 70–85 秒，超出的部分全是静止帧
- **6–12 秒的 "About Lyft" 企业介绍最伤**：刚用一个好问题勾住观众，立刻转去念公司简介，动能全泄。
  苹果从不解释自己是谁。压缩到 3 秒或移到片尾
- 后半段 "Research → Persona → Problem → Question → Journey" 连续 45 秒全是文字板，
  没有产品画面。旅程曲线要做成真正的绘制动画，饼图要做成增长动画
- 结尾缺一个**停顿**：产品锁定画面出现后需要约 1.5 秒纯净静场（音乐收、字幕清空、只剩 logo）

### 7. 声音

- 旁白是 macOS 系统 TTS，合成感明显，这是廉价感的一半来源。**换真人录音**
- `music-full.wav` 是 96 秒，视频 104 秒，代码里在做分块循环拼接，接缝处会听到
- 音乐没有卡点。至少在 "Street View" 揭晓那一刻给一个起势/留白
- 旁白进来时音乐需要 ducking（压 6dB）

### 8. 粉色用超了

`PLAN.md` 自己写了"粉色只用于关键节点、路径和转场"，但封面那个巨大的粉色圆占了半个画面且一直存在。
让它作为转场元素动起来（从一点扩张成圆，或从圆收缩成下一幕的元素），而不是当静态背景板。

**另外**：不要用整屏粉色闪白做转场。试过，0.8 透明度持续 0.4 秒会变成一整帧纯粉，非常廉价。

## 二、【重要】必须避免的抖动问题

这一节是重制时最容易踩的坑。缓慢运镜下，以下四件事**每一件都会单独造成肉眼可见的抖动**：

1. **图层位置不能取整**。如果每帧把绘制坐标 `round()` 成整数像素，而运镜每帧只移动 0.3px，
   图层就会连续几帧不动、然后突然跳 1px——这就是阶梯式抖动。
   **必须用亚像素精度绘制**（CoreGraphics 的 `CGContextDrawImage` 接受浮点 rect，直接用浮点坐标）。

2. **图层尺寸不能每帧重新取整重采样**。缓慢缩放时尺寸每帧变化不到 1px，取整后会在两个尺寸之间跳，
   边缘持续闪烁。**用变换矩阵做缩放，不要每帧 resize 位图**。

3. **重采样质量不能降级**。缓慢平移 4K 稿子时，双线性插值会让细小文字产生摩尔纹闪烁。
   **必须用高质量插值**（`CGContextSetInterpolationQuality(.high)`），不要为了速度降成 bilinear。

4. **颗粒必须每帧重新随机**。如果用一张固定噪声图做位移复用，视觉上会变成"爬行"的纹理而不是颗粒。

另外：**不要在同一个镜头里切换不同分辨率的源图**（比如推进时才换成 4K 原图），
切换瞬间锐度会突变，看起来像跳帧。整个镜头用同一个源。

### 【关键】11 和 12 不是同一张稿子的两个状态

原片把 `12.png` 的元素叠在 `11.png` 上做高亮，导致 **"Location Setting" 等标签重影**。

实际上这是**两张版式不同的稿子**：

- `11.png`：完整旅程，7 个节点，小字号
- `12.png`：只有 2 个关键节点，大字号，位置完全不同

正确做法是把它们当作两幕，用横向 wipe（从左到右）从 11 过渡到 12——
既避免重影，又契合"沿旅程推进"的语义。

### 旁白

`narration-cues/` 里有 22 条 cue 音频，对应 `narration-cues.json`。
去掉首尾静音后（阈值 -45dB）总时长 **80.25 秒**。

按同场景间隔 0.25 秒、跨场景间隔 0.55 秒、片头 1.2 秒、片尾 2.6 秒排布，
总时长约 **92 秒**，符合目标区间。

## 四、验收标准

1. 帧间差 < 0.06 的秒数 = **0**（用缩放到 160x90 的灰度帧间差测量）
2. 无单帧帧间差 > 12 的硬跳变
3. 成片时长 85–95 秒
4. 所有元素的**终态**必须精确落回原稿的位置、比例和边距
5. 逐帧检查缓慢运镜段落，确认无 1px 阶梯抖动
6. 转场处无鬼影、无字幕重影

## 五、参考

- **Apple**：保留单一主角，通过焦点推进和匹配剪辑把观众带入产品界面
